# C++ bot template

A starter bot: it places pegs on the first free square and stretches each rubberband around a
single peg, which scores one point. Write your strategy in the section marked
`EDIT ONLY THIS SECTION`.

Copy this whole folder to `bots/<your-name>/`. The referee finds it there by itself.
Working examples are in `bots/samples/`. See the main README, "Making a bot".
