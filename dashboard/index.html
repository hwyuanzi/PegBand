PegBand

architecture & tournament referee

1 Bots

Read from bots.json, plus any folder dropped into bots/ that holds a bot.py, bot.cpp or bot.jl.

2 Parameters

Each file holds the board side N, the pegs each player places and the rubberbands each player may lay down. The spec allows N up to 50, at most 20 pegs, and no more rubberbands than pegs.

3 Pairings

Each pairing is two games with the same parameters: Green places first and wins a tie, Blue places second. Bot 1 is Green in game 1 and Blue in game 2, so each bot plays each colour once. A team's score is its points over both games added together, and the higher total wins the pairing.

Choose bots and pairings, then start.
